# Word-Search-Game
🧩 Word Search Game – Python Tkinter
A simple and interactive Word Search Game built using Python's Tkinter library. Users can search for predefined words hidden in a 10x10 grid. The game visually highlights selected letters and gives immediate feedback on correct or incorrect guesses.

🔍 Features
✅ 10x10 letter grid

✅ Interactive button-based UI

✅ Highlight matching words in green, incorrect attempts in red

✅ Predefined word list display

✅ Reset and quit functionality

✅ Error handling for duplicate selections
